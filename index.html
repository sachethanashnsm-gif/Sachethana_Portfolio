Infrared Thermography Data Modeling & Dimensionality Reduction

Overview

Performed an advanced multivariate statistical analysis to model complex relationships between facial thermal image features and environmental conditions.

Key Contributions

  • Data Preprocessing: Cleansed complex structural data using mean imputation and transformed categorical variables via label encoding.
  • Anomaly Detection: Deployed the Isolation Forest algorithm to successfully identify and filter out extreme outliers.
  • Dimensionality Reduction: Applied Principal Component Analysis (PCA) and feature scaling to condense high-dimensional data into core variance components.
  • Latent Structure Modeling: Executed Factor Analysis (FA) with Varimax rotation to uncover hidden physiological variable groupings.
  • Relational Analysis: Utilized Canonical Correlation Analysis (CCA) to evaluate structural dependencies between environmental constraints and thermal readings.

Tools & Technologies

  • Language: Python
  • Libraries: scikit-learn (PCA, CCA, Isolation Forest), factor_analyzer, pandas, numpy, seaborn, matplotlib

Optimization of Industrial Recycling Collection Networks

Overview

Developed an Operations Research optimization model and interactive web application to determine the most cost-effective location for a centralized industrial waste processing facility.

Key Contributions

  • Mathematical Modeling: Formulated a Single Facility Location Model to minimize transportation and operational costs for handling high volumes of varied industrial waste.
  • Geospatial Processing: Processed and mapped national boundaries, environmental exclusion zones, and strict safety buffer zones using spatial Python libraries.
  • Algorithmic Optimization: Deployed the L-BFGS-B algorithm to pinpoint exact optimal geographic coordinates while strictly enforcing all spatial and regulatory constraints.
  • Application Development: Engineered a user-friendly Streamlit web application enabling stakeholders to input zone details and dynamically visualize the recommended facility location on a map.

Tools & Technologies

  • Language: Python
  • Libraries: scipy.optimize (L-BFGS-B), geopandas, shapely, pandas, numpy, matplotlib
  • Techniques & Deployment: Operations Research, Geospatial Analysis, Streamlit
