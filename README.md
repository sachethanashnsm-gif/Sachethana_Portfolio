*   **CSS3:** Custom styling, CSS Grid/Flexbox layouts, hover animations, and fully responsive mobile design.
*   **JavaScript:** Interactivity, including dynamic pop-up modals and smooth scrolling.
*   **FontAwesome & Unsplash:** Iconography and high-quality imagery.
